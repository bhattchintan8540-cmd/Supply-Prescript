# Stakeholders

| Stakeholder | Interest | How the system helps |
|---|---|---|
| Supply-chain planner | On-time material for production | Options + constrained recommendation |
| Procurement | Cost and supplier risk | Expected-cost comparison vs no action |
| Finance / FP&A | Budget control and ROI of expedites | Budget-feasible MILP; true ROI vs Delay Launch |
| Plant operations | Whether partial receipts are usable | Makespan vs weighted-average delay modes |
| Data / analytics | Model validity and drift | Temporal validation, baselines, retrain trigger |
| Interviewer / reviewer | Honest analytical claims | Business docs + explicit synthetic-data caveats |
